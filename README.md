# Ada Basar — Project Portfolio

Computer science student at USC. This repository collects my projects in one place, from Android apps and full-stack web development to machine learning.

> Each folder under [`projects/`](projects/) is a copy of a project from GitHub, with its own README explaining what it does and how to run it. Team projects link back to the original repository.

## Projects

| Project | What it is | Tech |
|---|---|---|
| [TradeOff — Stock Trading League](projects/tradeoff-stock-trading-league/) | Web app where friends compete in leagues with simulated stock portfolios using live market prices *(team, CSCI 201)* | Java, Servlets, MySQL, JavaScript |
| [Predicting F1 Race Outcomes](projects/f1-race-outcome-prediction/) | ML models that predict podium / top-ten finishes from pre-race data; I built the leak-free feature pipeline *(team, CSCI 467)* | Python, pandas, scikit-learn |
| [TrojanRideShare](projects/trojan-rideshare/) | Android app for USC students to post, find and split the cost of shared rides *(team, CSCI 310, in progress)* | Java, Android, Firebase |
| [Minesweeper for Android](projects/minesweeper-android/) | Minesweeper game with flagging, auto-reveal, a timer and a results screen | Java, Android |
